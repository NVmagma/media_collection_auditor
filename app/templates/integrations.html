Library coverage

GET /api/v1/coverage reports folder counts, missing/invalid/future dates and records without a matching stage folder. Optional query: library=Movies or library=TV. Enable explicitly with INTEGRATION_API_COVERAGE=true in the container template. It reads configured local folders only; no Jellyfin requests or media changes. Partial coverage returns 503 with unknown aggregate totals. A mismatch is a review finding, not proof that media was deleted.

Scan observations

GET /api/v1/scan-history supports page (default 1), page_size (1–20, default 5) and outcome (all, completed, review, unknown). Up to 100 attempts are retained in the current SQLite worker process. History resets after restart; separate API containers and legacy workers return unavailable.

GET /api/v1/proposals reports preview counts for the latest recorded attempt. It does not list titles or authorize actions. While a scan runs, the current status and prior recorded attempt are identified separately. Neither endpoint triggers a scan.

Diagnose a connection

  • 401 Unauthorized: token missing or incorrect. A browser sign-in cannot replace Bearer authentication.
  • 404: check the path; title routes also return 404 when title details are disabled. Missing or invalid server token configuration disables the API.
  • 400: library must be exactly Movies or TV, with only one library query value.
  • 503: tracking, preview binding or coordinator information is unavailable; this is not a healthy empty result.
  • External request failed: check the base URL, dashboard private-network access, connectivity and timeouts. This message alone cannot identify the cause.

Authenticated GET /api/v1/readiness lists supported routes and tracking readiness without collecting Jellyfin data. /health checks the web process only.

Replace the integration token

  1. Generate a new random token locally: docker exec media_collection_auditor python -c 'import secrets; print(secrets.token_urlsafe(32))'. Keep it private.
  2. In the existing Unraid template, replace only INTEGRATION_API_TOKEN and apply the container change. Preserve the image reference, three mounts, read-only flags and other settings.
  3. Replace the Bearer credential in every Homarr/Homepage widget. Verify the new token returns 200 from readiness; the previous token must return 401.

Token replacement requires container recreation. This page does not change credentials or services. Never paste tokens into URLs, screenshots, logs or support messages.
